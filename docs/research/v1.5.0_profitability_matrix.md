# v1.5.0 長期盈利可行性 — 評估矩陣

> **評分規則**
>
> - `系統能力分`: 系統架構上是否已具備這種能力
> - `證據成熟度分`: 這種能力是否已被足夠驗證
> - 分數範圍 `0-4`

---

## 1. 主矩陣

| 評估維度 | 系統能力分 | 證據成熟度分 | 支持證據 | 關鍵缺口 | 若不解決的風險 |
|---|:---:|:---:|---|---|---|
| Alpha 可得性 | 2 | 1 | `qlib_market_scanner` 已有 FX profile、dynamic cost、walk-forward / cost sensitivity 腳手架；scanner schema 已可供下游排序與過濾 | FX universe 太小；intraday 支援仍帶 compatibility hack；尚無整體系統成本後 OOS 證據 | 可能只是研究上可運作，production 上沒有持續 alpha |
| Execution 可實現性 | 3 | 2 | `prop-firm-pilot` 有 pre-trade quote、slippage / latency metadata、close control plane、write-budget 控制、broker reconciliation | live evidence 仍有限；執行保護主要驗證的是安全，不是正期望保留 | 方向判對但被成本、延遲、partial fill、broker behavior 吃掉 |
| Risk / Portfolio 可控性 | 2 | 1 | compliance、drawdown monitor、best-day、reduce exposure 已存在 | 沒有 portfolio-level exposure budget、correlation guard、capital allocator | 單筆安全但組合層面集中暴露，回撤與容量不可控 |
| Learning / Adaptation 可持續性 | 2 | 1 | historical pnl context、market event context、memory retrieval、reflect loop、entry calibration snapshot 都已存在 | 缺單一 trade-memory contract；lesson quality gate 不清楚；LLM 記憶容易混入噪音 | 系統以為自己在學習，實際上在累積錯誤樣本與 prompt 漂移 |
| Research / Validation 嚴謹性 | 2 | 1 | scanner repo 有 walk-forward、cost sensitivity；pilot 有大量 journaling 與 replay | 缺 integrated release gate；未見 DSR / PBO 類型的 selection-bias control；缺 live-vs-backtest consistency 框架 | 容易把局部正面結果誤判成長期盈利證據 |

---

## 2. 綜合判讀

| 指標 | 分數 |
|---|:---:|
| 平均系統能力分 | 2.2 |
| 平均證據成熟度分 | 1.2 |

### 解讀

- **能力面**: 系統已超出「概念驗證」階段，具備長期系統候選的部分底盤。
- **證據面**: 仍明顯不足，尤其缺少 portfolio 與 integrated validation 的成熟證據。
- **最強的一項**: `Execution 可實現性`
- **最弱的兩項**: `Alpha 可得性` 與 `Risk / Portfolio 可控性`

---

## 3. 紅線問題

以下問題若未解決，不應宣稱本系統具備長期盈利能力:

1. **沒有成本後、跨 regime 的整體系統 OOS 驗證**
2. **沒有 portfolio-level exposure / correlation guard**
3. **沒有把 LLM 決策層做成可審計、可約束、可對照 ablation 的風險輸出**
4. **沒有統一 trade-memory schema 與 quality gate**
5. **沒有把 scanner / agent / pilot 的跨 repo contract freeze 成 release gate**

---

## 4. 初步結論等級

### 當前結論

- **結論等級**: `具備局部合理性，但距離長期盈利系統仍有關鍵缺口`

### 為何不是更高等級

- `v1.5.0` 方向正確，但目前看到的是:
  - 強 control plane
  - 有研究腳手架
  - 有 memory 與 reflection 雛形
- 仍不是:
  - 已證明持續成本後 alpha
  - 已證明 portfolio 層可控
  - 已證明 LLM 層在 intraday FX 下穩定有效

### 條件式上限

- **條件式推論**: 若 `v1.5.0` 真正完成 exposure budget、scanner cadence research、TradingAgents intraday contract、memory quality gate、以及 integrated validation gate，則系統有機會上調到:
  - `具備成為長期盈利候選系統的條件，但仍缺關鍵驗證`
- 但在那些 gate 完成前，不宜上調。
