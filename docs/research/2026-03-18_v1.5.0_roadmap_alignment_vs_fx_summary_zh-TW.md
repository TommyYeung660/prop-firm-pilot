## 4. 對齊分數

我會給兩個分數：

- `方向對齊`: `8/10`
- `已落地程度`: `5/10`

### 為什麼方向有 8 分

因為 roadmap 沒有落入最常見的錯誤：

- 沒有把 LLM 寫成萬能 alpha engine
- 沒有忽略成本與驗證
- 沒有把 `1.5.x` 主題寫成模型軍備競賽
- 已承認 contract、validation、execution、risk 的優先級更高

### 為什麼落地只有 5 分

因為 summary 最看重的幾個閉環還沒完成：

- portfolio-level exposure / correlation guard
- aggregate open-risk reservation
- live-vs-research consistency review
- trade-memory quality gate

## 5. 建議下一步

如果要讓 roadmap 更貼近這份 summary，下一步最該補的不是新模型，而是：

1. `先補 exposure / aggregate open-risk guard`
   讓 risk overlay 從單筆風控升級到組合層。

2. `把 live-vs-research consistency 做成固定 acceptance artifact`
   不再只是文件中的要求。

3. `為 trade-memory 加上 quality gate`
   讓 memory 保持「有幫助的增強器」，而不是噪音累積器。

4. `把 scanner / downstream 的 regime 與 cost evidence 統一成可回放對帳`
   讓 summary 裡強調的 cost-aware / regime-aware 方法論在系統層真正閉環。

5. `在 1.5.x 後段才討論更深的 LLM / RL / agent alignment`
   前提是前面四件事已收斂，否則容易變成敘事先行。

## 6. 最後判斷

`這個項目目前沒有偏離 summary 的大方向。`

但更準確的說法是：

`它現在比較像 cost-aware scanner + bounded LLM + execution/control-plane hardening 的系統，還不是完整的 simple-ML / factors / regime / portfolio-risk overlay 系統。`

所以如果之後 roadmap 繼續把重心放在：

- exposure
- validation
- memory quality
- research-to-live consistency

那就會越來越接近這份 summary 所支持的方向；反過來，如果太早把主軸轉去更重的 LLM 敘事或更複雜模型敘事，反而會開始偏離。
