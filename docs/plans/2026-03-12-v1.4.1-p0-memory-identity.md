# v1.4.1 P0 Memory Identity Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Make `MemoryJournal` append trade results to the correct decision anchor by `intent_id`, and reject cross-symbol mismatches.

**Architecture:** `Scheduler` already logs decisions with `intent_id`. `MemoryJournal` will use that as the decision anchor, resolve the original file by `intent_id`, verify `symbol` inside the anchored block, then append the result to that anchored file instead of today's file.

**Tech Stack:** Python 3.10, pytest, loguru, local Markdown journal files
