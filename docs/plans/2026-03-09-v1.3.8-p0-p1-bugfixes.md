## Task 1: Fix TradingAgents `self.ticker` Race Condition (Issue #15, P0)

**Files:**
- Modify: `../../TradingAgents/tradingagents/graph/trading_graph.py:311-393` (propagate), `395-435` (_log_state)
- Test: `../../TradingAgents/tests/test_propagate_thread_safety.py` (Create)

**Context:** `TradingAgentsGraph` is a single shared instance. When multiple async workers call `propagate()` concurrently (via `asyncio.to_thread`), `self.ticker` and `self.curr_state` get overwritten by the second caller before the first finishes. This causes eval logs to write to the wrong directory and `reflect_and_remember()` to operate on the wrong state.

## Task 6: Fix EURUSD Over-Filtering / Threshold Calibration (Issue #1/#6, P1)

**Files:**
- Modify: `src/optimize/thresholds.py:25-30`
- Modify: `src/scheduler/scheduler.py:1779-1781` (_blend_confidence formula)
- Test: `tests/test_thresholds.py` (Create)

**Context:** With global `min_blended_confidence=0.65` and `symbol_thresholds={}` (empty), ALL symbols use the global threshold. The blended confidence formula is `0.6 * confidence_score + 0.4 * scanner_score`. EURUSD scanner scores are consistently ~0.38-0.39. Even with `confidence_score=0.67` ("high"), blended = `0.6*0.67 + 0.4*0.39 = 0.558` — well below 0.65. So EURUSD never passes.

**Root issue:** The stepwise threshold for `win_rate < 0.45` jumps straight to `high/0.65`, which is too strict for a cold-start system (no win-rate data = defaults to 0.0 win-rate).

**Step 1: Write the failing test**
