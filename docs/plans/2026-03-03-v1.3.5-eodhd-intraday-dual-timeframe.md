## Task 1: qlib_market_scanner — Add `fetch_intraday()` to EODHDFXFetcher

**Repo:** qlib_market_scanner
**Files:**

- Create: `tests/test_fx_fetcher_intraday.py`

**Context:**
- `EODHDFXFetcher` class is at line 265-358 of `fx_fetcher.py`. It currently only has `fetch_daily()` using `/api/eod/`.
- The existing `download_universe()` function (line 360-474) handles daily downloads. We need a parallel `download_universe_intraday()` for hourly data.
- EODHD Intraday API uses Unix timestamps (`from`/`to` params), NOT date strings like the EOD API.
- Response format: `[{datetime: "2026-03-01 10:00:00", gmtoffset: 0, open, high, low, close, volume}, ...]`
- All timestamps are UTC.

**Requirements:**
1. Add `fetch_intraday(self, symbol: str, start: str, end: str, interval: str = "1h") -> pd.DataFrame` method to `EODHDFXFetcher`:
   - Endpoint: `GET {BASE_URL}/api/intraday/{eodhd_symbol}`
   - Convert `start`/`end` from "YYYY-MM-DD" to Unix timestamps (UTC)
   - Params: `api_token`, `interval` ("1h"), `from` (unix), `to` (unix), `fmt` ("json")
   - Return DataFrame with columns: `date`, `open`, `high`, `low`, `close`, `adj_close`, `volume`
   - Parse `datetime` field from response as the `date` column (pd.to_datetime)
   - Set `adj_close = close` (same as daily does)
   - Handle retries + rate limit (429) same as `fetch_daily()`
   - Log with loguru, same patterns as existing code
   - FX volume may be 0 — that's fine, keep it as-is

2. Add `aggregate_to_4h(df: pd.DataFrame) -> pd.DataFrame` module-level function:
   - Input: 1H OHLCV DataFrame with `date` column (datetime)
   - Output: 4H OHLCV DataFrame
   - Aggregation: group by 4-hour blocks anchored at UTC 00:00 (00:00, 04:00, 08:00, 12:00, 16:00, 20:00)
   - OHLC rules: open=first, high=max, low=min, close=last, volume=sum, adj_close=last close
   - Use `pd.Grouper(key="date", freq="4h", origin="start_day")` or equivalent
   - Drop any incomplete bars (bars with fewer than expected candles at edges)

3. Add `download_universe_intraday()` function (parallel to existing `download_universe()`):
   - Same signature pattern: `(tickers, start, end, output_dir, interval="1h", max_retries=3, backoff_factor=1.0, cache_max_dates=None) -> List[Path]`
   - Uses `EODHDFXFetcher.fetch_intraday()` internally
   - Output CSVs have same column structure as daily (date, open, high, low, close, adj_close, volume) but with datetime timestamps
   - Support incremental fetch using `cache_max_dates` (same pattern as daily)
   - Rate limit: `time.sleep(1)` between tickers (EODHD generous limit)

**MUST NOT:**
- Modify existing `fetch_daily()` or `download_universe()` functions
- Break backward compatibility with daily pipeline
- Use `aiohttp` or `httpx` (this module uses sync `requests`)

**Tests:** (in `tests/test_fx_fetcher_intraday.py`)
