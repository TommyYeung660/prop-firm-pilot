# v1.5.0_beta_2 Roadmap Update Design

**Date:** `2026-03-17`

**Goal:** 在 `docs/PropFirmPilot_v1.5.0_road_map.md` 中，明確定義 `v1.5.0_beta_2` 為 stable 前的 operational repair gate，並把「資金使用率偏低」從 repair 範圍移出，改列為 `v1.5.0_stable` 的 bounded optimization。

## Approved Direction

採用方案 2：

- 在 `v1.5.0 stable` 前新增 `v1.5.0_beta_2` 版本定位
- 以嚴重度排序修復清單
- 明確把 `資金使用率偏低` 標記為優化，不屬於 `beta_2`
- 將該優化改掛到 `v1.5.0_stable`

## Scope

納入 `v1.5.0_beta_2`：

- 市場資料 freshness / websocket 退化保護
- stale signal hard block
- tactical pending timeout / expired claim recycle 修復
- EquityMonitor transaction 問題
- Telegram tactical gate 限流
- operator diagnostics / incident bundle 補強

不納入 `v1.5.0_beta_2`：

- 資金使用率偏低
- 完整 capital efficiency / portfolio construction
- scanner cadence promotion

## Roadmap Changes

1. 更新文件標頭日期與當前主線狀態
2. 在現況總結中加入 `beta_2` 與 `stable` 的責任切分
3. 在波段總覽加入 `v1.5.0_beta_2`
4. 新增 `v1.5.0_beta_2` 詳細章節，含按嚴重度排序的修復清單
5. 更新 `v1.5.0 stable` 章節，納入 bounded capital utilization uplift
6. 更新 cross-repo table 與一句話總結
