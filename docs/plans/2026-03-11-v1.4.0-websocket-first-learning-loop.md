# v1.4.0 WebSocket-First Learning Loop Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build `v1.4.0` across `prop-firm-pilot` and `TradingAgents` so that market data becomes WebSocket-first with REST fallback, while closed-trade outcomes are persisted and retrieved as decision-time lessons.

**Architecture:** Add a new WebSocket ingestion and aggregation pipeline inside `prop-firm-pilot`, route volatility/tactical observation through a market-data hub, keep MatchTrader/news/cold-start on REST fallback, and enrich the reflection pipeline so `TradingAgents` stores and reuses outcome-aware memory during later decisions.

**Tech Stack:** Python 3.10, asyncio, websockets/httpx, Pydantic v2, pytest, loguru, ChromaDB, OpenAI-compatible embeddings.
