# v1.5.0 Side-Aware Live Activation Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Activate end-to-end side-aware FX scanner ingestion across `qlib_market_scanner` and `prop-firm-pilot`, with live `topk_short = 1`, direction-aware thresholding, side persistence, and hard rejection of LLM decisions that invert scanner direction.

**Architecture:** `qlib_market_scanner` remains the producer of `fx_signal_v2` side-aware bundles and gains an explicit `topk_short` runtime control. `prop-firm-pilot` becomes a dual-schema consumer that parses `side`, persists `scanner_side`, ranks mixed long/short candidates by direction-aware quality, and only allows TradingAgents to confirm or veto the scanner-provided direction.

**Tech Stack:** Python 3.10, Pydantic v2, SQLite, loguru, pytest, uv, cross-repo subprocess integration.
