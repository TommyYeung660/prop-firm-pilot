# v1.5.0 Preview Bounded Capital Utilization Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 為 `prop-firm-pilot` 實作 bounded capital utilization uplift，讓 sparse portfolio 的高品質 setup 可以有紀律地使用更多既有風險預算，並同步將版本更新為 `1.5.0_preview`。

**Architecture:** 新增一個 execution-side capital allocation helper，根據 `default_risk_pct * max_positions` 形成的名目風險預算、當前 open positions 與 scanner confidence，計算單筆 `effective_risk_pct`。`PositionSizer` 支援 risk override，`ExecutionEngine` 在 build trade plan 時套用該值並保留 audit metadata。最後更新 roadmap 與版本 identity。

**Tech Stack:** Python 3.10, Pydantic, pytest, uv, Markdown.

### Task 2: 實作 capital allocation helper

**Files:**
- Create: `src/execution/capital_allocator.py`

**Step 1: Write minimal implementation**

實作：

- `CapitalAllocationDecision`
- `BoundedCapitalAllocator`
- `allocate_entry_risk(open_positions, scanner_confidence)`

規則：

- `portfolio_budget_pct = default_risk_pct * max_positions`
- `slot_budget_pct = portfolio_budget_pct / max(open_positions + 1, 1)`
- `bounded_cap_pct = min(slot_budget_pct, max_risk_pct)`
- `confidence_factor = {"high": 1.0, "medium": 0.5, "low": 0.0}`
- `effective_risk_pct = default_risk_pct + confidence_factor * (bounded_cap_pct - default_risk_pct)`

**Step 2: Run test to verify it passes**

Run: `uv run pytest tests/test_capital_allocator.py -q`

Expected: PASS.
