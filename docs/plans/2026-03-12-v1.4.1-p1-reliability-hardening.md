# v1.4.1 P1 Reliability Hardening Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Fix the v1.4.1 P1 production issues: version drift, Telegram polling degradation observability, and WebSocket degraded REST fallback bloat.

**Architecture:** Introduce a single runtime version helper sourced from `pyproject.toml`, thread shared operational metrics into the Telegram polling path, and make `MarketDataHub` refresh stale REST-backed data incrementally instead of repeatedly fetching full fixed lookback windows. Keep the existing WebSocket-first control flow and only harden degraded-mode behavior and telemetry.

**Tech Stack:** Python 3.10, asyncio, loguru, httpx, pandas, pytest, ruff
