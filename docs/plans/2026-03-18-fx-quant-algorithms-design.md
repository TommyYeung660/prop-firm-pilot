# FX 量化分析算法研究報告設計

**日期:** `2026-03-18`

**Goal:** 撰寫一份面向研究讀者的繁體中文 Markdown 總結，整理現時常見的 FX 量化分析算法、它們的基本原理、近年文獻對有效性的看法，以及實務上常見的失效原因。

**Report Positioning:** 這是一份研究導向的總結報告，不是策略推介、不做績效承諾，也不把單篇回測論文當成可直接實盤複製的證據。全文會優先使用官方研究機構與學術來源，並以簡單易明的語言說明。

---

## 1. 研究範圍

- 聚焦 `FX spot / forward / cross-currency` 的量化分析方法。
- 聚焦中低頻到中高頻研究框架，不深入 HFT 硬體競賽或做市基礎設施細節。
- 納入統計模型、因子法、機器學習、深度學習、強化學習、新聞/文本融合、order flow / LOB 類方法。

---

## 2. 有效性判準

報告固定用以下判準評估每類算法：

1. 是否存在樣本外預測力
2. 扣除交易成本後是否仍可用
3. 是否高度依賴特定市場 regime
4. 是否容易解釋、維護與監控
5. 是否需要一般團隊難以取得的資料或基礎設施

---

## 3. 報告結構

正式報告分成六段：

1. 市場背景與核心結論
2. 如何判斷「有效」
3. 主流算法總覽表
4. 各類算法的簡單說明與有效性評估
5. 哪些做法現在較可取，哪些容易失效
6. 來源清單

---

## 4. 寫作原則

- 預設繁體中文
- 首次出現術語時，用白話補一句說明
- 對結論使用保守語言
- 明確區分「研究證據」與「實務推論」
- 每一節盡量附一句話結論，方便快速閱讀
