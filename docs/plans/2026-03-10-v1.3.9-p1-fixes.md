## Task 1: Breakeven Stop — Read-Back Verification

**Problem:** `modify_position()` returns `success=True` based on API status "OK" but never verifies the SL was actually updated at the broker. Race condition: SL moved to entry at 21:49 but positions closed at 21:51-21:55 with -$24/-$25 loss.

**Root cause:** `_apply_breakeven_stops()` trusts `result.success` without read-back. Also, `_handle_position_closed()` compares `close_price` to `execution_meta.sl_price` (the **original** SL), not the breakeven-modified SL.

**Fix approach:**
1. Add `verify_sl_tp()` method to `MatchTraderClient` that reads back position after modify.
2. In `_apply_breakeven_stops()`, call verify after successful modify and retry once if mismatch.
3. Store breakeven SL in `execution_meta` so `_handle_position_closed()` uses correct SL for exit_reason inference.

**Files:**
- Modify: `src/execution/matchtrader_client.py` (add `verify_sl_tp` method, ~L817)
- Modify: `src/scheduler/scheduler.py` (update `_apply_breakeven_stops` ~L1467, update `_handle_position_closed` ~L1241)
- Test: `tests/test_breakeven_verification.py` (new file)

async def verify_sl_tp(
    self,
    position_id: str,
    expected_sl: float | None = None,
    expected_tp: float | None = None,
    tolerance: float = 1e-6,
) -> bool:
    """Read back open position and verify SL/TP match expected values.

    Used after modify_position() to confirm the broker actually applied
    the SL/TP change. Returns False if position not found or values mismatch.

    Args:
        position_id: The position to verify.
        expected_sl: Expected stop loss price (None = don't check).
        expected_tp: Expected take profit price (None = don't check).
        tolerance: Price comparison tolerance (broker may round).
    """
    try:
        positions = await self.get_open_positions()
        for pos in positions:
            if str(pos.position_id) == position_id:
                if expected_sl is not None:
                    actual_sl = pos.sl_price or 0.0
                    if abs(actual_sl - expected_sl) > tolerance:
                        logger.warning(
                            "MatchTrader: verify_sl_tp MISMATCH for {} — "
                            "expected SL={}, actual SL={}",
                            position_id, expected_sl, actual_sl,
                        )
                        return False
                if expected_tp is not None:
                    actual_tp = pos.tp_price or 0.0
                    if abs(actual_tp - expected_tp) > tolerance:
                        logger.warning(
                            "MatchTrader: verify_sl_tp MISMATCH for {} — "
                            "expected TP={}, actual TP={}",
                            position_id, expected_tp, actual_tp,
                        )
                        return False
                return True
        logger.warning(
            "MatchTrader: verify_sl_tp — position {} not found (may be closed)",
            position_id,
        )
        return False
    except Exception as e:
        logger.error("MatchTrader: verify_sl_tp error for {}: {}", position_id, e)
        return False
```

        logger.info(
            "AgentBridge: attempting fallback to '{}' for {}",
            self._fallback_model, symbol,
        )
        try:
            self._apply_ab_model(self._fallback_model)
            final_state, decision = self._graph.propagate(
                company_name=symbol,
                trade_date=normalized_trade_date,
                qlib_data=qlib_data,
            )
            model_id = self._fallback_model

            # ... (same risk_report extraction + validate_decision as primary path)
            risk_report = ""
            if isinstance(final_state, dict):
                if "trader_investment_plan" in final_state and final_state["trader_investment_plan"]:
                    risk_report = str(final_state["trader_investment_plan"])
                elif "risk_debate_state" in final_state and "judge_decision" in final_state["risk_debate_state"]:
                    risk_report = str(final_state["risk_debate_state"]["judge_decision"])
                elif "investment_debate_state" in final_state and "judge_decision" in final_state["investment_debate_state"]:
                    risk_report = str(final_state["investment_debate_state"]["judge_decision"])
                else:
                    risk_report = final_state.get("risk_report", "")

            validated_decision = validate_decision(
                raw_decision=decision, risk_report=risk_report, symbol=symbol,
            )
            result = AgentDecision(
                symbol=symbol,
                decision=validated_decision,
                final_state=final_state if isinstance(final_state, dict) else {},
                risk_report=risk_report,
                model_id=model_id,
            )
            logger.info(
                "AgentBridge: FALLBACK {} → {} (model={})",
                symbol, decision, model_id,
            )
            return result

        except Exception as fallback_error:
            logger.error(
                "AgentBridge: fallback also failed for {}: {}",
                symbol, fallback_error,
            )

    # Both primary and fallback failed (or no fallback available)
    return AgentDecision(
        symbol=symbol,
        decision="HOLD",
        final_state={"error": str(primary_error)},
        risk_report=f"Error during agent decision: {primary_error}",
    )
```

## Task 4: No Data = No Trade — Block on Missing Risk Data

**Problem:** When spread/ATR/freshness data is missing (e.g., EODHD down), tactical validation passes through by default, allowing trades without proper risk checks.

**Root cause:** The `except Exception` in `_run_tactical_validation()` (~L782-793) returns `TacticalResult(action="PASS")` on any error, including missing data scenarios.

**Fix approach:**
1. Change tactical error fallback from "PASS" to "WAIT" (retryable) or "REJECT" (permanent).
2. In `TacticalValidator.evaluate()`, add explicit check: if ALL hard gate inputs are missing/zero, return REJECT.

**Files:**
- Modify: `src/scheduler/scheduler.py` (`_run_tactical_validation` ~L769)
- Modify: `src/decision/tactical_validator.py` (add no-data guard in `evaluate()`)
