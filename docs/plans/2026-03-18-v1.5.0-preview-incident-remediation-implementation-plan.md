# v1.5.0 Preview Incident Remediation Implementation Plan

> Historical implementation-plan artifact preserved from local `main` during remediation merge preparation.

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 修正 `v1.5.0_preview` production incident 的 P0/P1 問題，先消除錯誤的 Best Day 拒單與 deterministic compliance churn，再將 market-data routing 調整為 `broker quote-first + API bars-first + websocket auxiliary`。

**Architecture:** `Best Day Rule` 對新單只看實際已發生的當日 PnL，compliance headroom 在 scheduler admission 前移，避免必定被拒的 candidate 浪費 LLM 與 tactical cycle。market-data 層改成混合式 API-first：live quote 改由 broker primary，closed bars 改由 EODHD API primary，websocket 降為輔助與遙測來源。scanner success contract 與 alerting resilience 一併補強。

**Tech Stack:** Python 3.10, Pydantic, pytest, uv, DuckDB/SQLite, Markdown.
