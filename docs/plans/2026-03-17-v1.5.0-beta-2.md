# v1.5.0_beta_2 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 完整落地 `v1.5.0_beta_2`，修復 stale signal、market-data degraded entry guard、tactical pending lifecycle、Telegram tactical noise、sqlite equity snapshot transaction overlap，並把 EODHD WebSocket ping-timeout 退化納入 entry safety。

**Tech Stack:** Python 3.10、pytest / pytest-asyncio、loguru、sqlite3、pydantic v2、asyncio、websockets、httpx
