# v1.4.8 Close Control Plane Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 建立 `CloseControlPlane` 與 `CloseReconciler`，把 tactical exit、drawdown de-risk、emergency close、best-day close、LLM re-eval close、以及 external detected close 收斂成單一 execution、read-back、journal、reconciliation 模型。

**Architecture:** 新增 close-domain typed models，讓所有主動 close/modify 路徑先建立 `CloseIntent`，再經由 `CloseControlPlane.execute()` 產生 `CloseOutcome`。position monitor 的 close detection 則交由 `CloseReconciler.reconcile()` 將 broker closed facts、pending outcome、execution_meta fallback 與既有 close-tracking 集合合併，產生 canonical `trigger_source / action_kind / final_close_reason`，並維持 `DecisionStore.exit_reason = final_close_reason` 的向後相容。

**Tech Stack:** Python 3.10, `dataclasses`, asyncio, `loguru`, existing MatchTrader REST client, JSONL `TradeJournal`, `pytest`, `ruff`
