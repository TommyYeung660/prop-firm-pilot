# v1.4.1 P2 Diagnostics And Bundle Hardening Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add usable throughput diagnostics for cooldown / cancel loops and make production log bundles self-consistent even when summaries are partially missing.

**Architecture:** Emit structured skip events from the scheduler for cooldown-driven scanner suppression, then generate a deterministic decisions summary from the trade journal that surfaces cancel reasons, skip reasons, and same-day follow-up outcomes. Harden the packer INDEX to reflect only files that actually exist, and always emit at least a fallback Telegram / decisions summary so postmortem bundles stay usable.

**Tech Stack:** Python 3.10, asyncio, JSONL trade journal, pytest, ruff
